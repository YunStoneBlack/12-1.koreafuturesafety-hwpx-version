Claude API 키

계약서 PDF로 현장 정보를 자동 인식하는 기능에 필요합니다. console.anthropic.com에서 발급받은 키를 입력하세요. 회사 전체가 공유하는 키입니다.

현장 삭제 비밀번호

현장을 삭제할 때 입력하는 회사 공용 비밀번호입니다. 이 비밀번호를 아는 사람만 현장을 지울 수 있습니다.

지도 출장 자동 배치

자동 배치는 남은 지도 회차를 공사 기간에 고르게 나눠 방문 예정으로 넣습니다(주말·공휴일·징검다리 휴일 빼고, 가까운 현장은 같은 날로). 마지막 지도는 준공일 며칠 전까지 마칠지 정하세요 — 현장 사정에 따라 언제든 바꿔도 됩니다.
현장끼리 거리는 카카오 내비 기준 자동차 도로 거리입니다(시간은 교통에 따라 달라 쓰지 않음). 같은 시·군이라도 멀면 다른 날로, 다른 시·군이라도 아주 가까우면 자리가 없을 때만 같은 날로 넣습니다.

지도 기한 알림

기한 = 마지막 지도일 + 15일. 평일 아침 9시에 담당요원(담당요원 탭의 메일)과 아래 관리자 메일로 임박·당일·초과를 현장마다 한 번씩 알립니다. 기한이 주말이면 금요일에 미리 알립니다.
