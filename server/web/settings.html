Claude API 키

계약서 PDF로 현장 정보를 자동 인식하는 기능에 필요합니다. console.anthropic.com에서 발급받은 키를 입력하세요. 회사 전체가 공유하는 키입니다.

현장 삭제 비밀번호

현장을 삭제할 때 입력하는 회사 공용 비밀번호입니다. 이 비밀번호를 아는 사람만 현장을 지울 수 있습니다.

지도 출장 자동 배치

자동 배치는 남은 지도 회차를 공사 기간에 고르게 나눠 방문 예정으로 넣습니다(주말·공휴일·징검다리 휴일 빼고, 가까운 현장은 같은 날로). 마지막 지도는 준공일 며칠 전까지 마칠지 정하세요 — 현장 사정에 따라 언제든 바꿔도 됩니다.
현장끼리 거리는 카카오 내비 기준 자동차 도로 거리입니다(시간은 교통에 따라 달라 쓰지 않음). 같은 시·군 가까운 현장끼리 먼저 묶고, 시·군이 달라도 한 사람의 그날 현장끼리 거리 안이면 같은 날로(인천·파주는 묶고 인천·속초는 다른 날로). 하루에 출장 나가는 사람은 회사 전체 하루 출장 인원까지입니다(비상 인력 — 넘으면 다른 날로).

지도 기한 알림

기한 = 마지막 지도일 + 15일. 평일 아침 9시에 담당요원(담당요원 탭의 메일)과 아래 관리자 메일로 임박·당일·초과를 현장마다 한 번씩 알립니다. 기한이 주말이면 금요일에 미리 알립니다.

결재란 도장 (이사 · 대표이사)

한 번 등록하면 이 회사의 모든 보고서 결재란에 자동으로 들어갑니다. 도장 스캔 이미지를 올리거나 직접 그릴 수 있습니다.

착수계·완수계 서류

현장 화면 [📑 착수계]·[📑 완수계]에 들어가는 자료입니다. 그림(JPG·PNG)이나 PDF(첫 장)를 올리거나 서류 줄에 끌어다 놓으세요. 유효기간이 지난 서류는 서류를 만들 때 경고합니다 — 새로 발급받아 바꿔 올리세요.

완수계 회사 서류 — 완납증명서는 올리면 발급일·유효기간을 자동으로 읽어 넣습니다(틀리면 고쳐서 [날짜 저장], 유효기간이 안 적혀 있으면 발급일 + 30일)

불러오는 중...

착수계 기술자 명단 — 현장대리인·참여기술자로 고르는 사람(담당요원과 따로). 경력증명서는 올리면 발급일을 읽어 넣습니다(유효기간 = 발급일 + 3개월)

시특법 보고서에 자동으로 들어가는 서류와 장비입니다. 한 번 올려 두면 모든 보고서에 쓰고, 유효기간이 지나면 보고서를 만들 때 알려 줍니다.

회사 원본 템플릿

정기 하나 · 정밀 본문·부록

정기 회차는 정기 원본 하나로 만듭니다(학교 보고서 기준 — 2종은 1.5 안전등급 평가·1.7 치장벽돌을, 3종 일반은 1.7을 빼고 씀). 정밀 회차는 회사 관행대로 본문·부록 두 원본(다산은혜교회 2026 상반기 보고서 기준)으로 한글 두 개 + 합본 PDF를 만듭니다. 오타를 고치려면 [한글 받기] → 한글에서 고쳐 저장 → [고친 한글 올리기]. 바꾸면 옛 원본은 따로 보관됩니다. 프로그램이 채우는 표·제목(결과표, 1.2.6~1.2.8 표, 1.3 항목, 1.4·1.5 표, 1.7)은 지우거나 이름을 바꾸지 마세요 — 올릴 때 검사합니다.
