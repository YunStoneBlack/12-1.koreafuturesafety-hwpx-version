Claude API 키

계약서 PDF 자동 인식에 씁니다 — 용역계약서는 글자로 먼저 읽고, 못 읽은 칸만 AI로 채웁니다(보고서 자동화와 같은 키). console.anthropic.com에서 발급받은 키를 입력하세요. 회사 전체가 공유하는 키입니다.

삭제 비밀번호

현장·용역 계약을 삭제할 때 입력하는 회사 공용 비밀번호입니다(보고서 자동화와 같은 비밀번호).

착수계·완수계 서류

현장 화면 [📑 착수계]·[📑 완수계]에 들어가는 자료입니다. 그림(JPG·PNG)이나 PDF(첫 장)를 올리거나 서류 줄에 끌어다 놓으세요. 유효기간이 지난 서류는 서류를 만들 때 경고합니다 — 새로 발급받아 바꿔 올리세요.

완수계 회사 서류 — 완납증명서는 올리면 발급일·유효기간을 자동으로 읽어 넣습니다(틀리면 고쳐서 [날짜 저장], 유효기간이 안 적혀 있으면 발급일 + 30일)
