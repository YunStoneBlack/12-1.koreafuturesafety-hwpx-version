정밀안전점검 4장 재료시험과 부록 성과표에 들어갑니다. 값을 넣으면 등급·기울기(1/N)·탄산화 잔존수명은 자동으로 계산되고, 고치는 대로 저장됩니다.

1. 표본층

층수·연면적으로 정한 수만큼 층을 고르세요. 고르면 아래 표에 기준 수량만큼 줄이 생깁니다(값을 넣은 줄은 층을 바꿔도 남음). 대표 범위는 자동으로 나누고(두 표본층 사이 가운데, 지하/지상 경계가 사이면 거기서) 고칠 수 있습니다.

2. 부재 규격 조사

표본층마다 2부재 × 3개소. 부재를 고르면 기둥·보는 가로·세로, 슬래브·벽체는 두께(mm)만 넣습니다. 조사결과가 설계와 같으면 "일치", 다르면 "다름"으로 바꾸고 실측값을. 상태평가 점수에는 안 넣고(민재형 10/13) 평가만 합니다.

🏢 시설물 현황 창의 도면 칸에 올린 "구조 일람표"를 읽어 빈 설계도면 칸만 채웁니다(위치 칸에 부재 기호)

3. 콘크리트 강도 (슈미트해머)

층·부재·부위·설계기준강도는 직접(성과표 위치 글자에 부재·부위가 있으면 자동). 추정강도(MPa) ÷ 설계기준강도 → a 100%↑ · c 85~100 · d 70~85 · e 70 미만(손상 있으면 b).

4. 탄산화 시험

잔여깊이 = 피복 − 깊이, 속도계수 A = 깊이/√경과년수, 잔존수명 = (피복/A)² − 경과년수(100년 넘으면 "100년 이상"), 등급 = 깊이/피복(0.25D·0.5D·0.75D·D).

5. 기울기 (수평변위)

건축물 외벽 모서리 4곳 × X·Y 두 방향 = 기본 8측점(더 재면 [+ 측점 추가]). 기울기 1/N = 측정높이 ÷ 변위량 → a 1/750 이하 · b 1/500 · c 1/250 · d 1/150 · e 초과.

6. 부등침하 (수직변위)

최하층 바닥을 레벨기로 — 장변(X)·단변(Y) 방향 각 2구간이 기본(X1·X2·Y1·Y2). 구간마다 측점 3개로 시작하고 더 재면 [+ 측점 추가]. 레벨(mm)과 측점 사이 거리(mm). 변위 = 앞 측점 − 뒤 측점, 기울기 = 거리 ÷ |변위|.
