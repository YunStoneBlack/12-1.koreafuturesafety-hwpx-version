# SafetyMan ↔ 우리 상태평가 비교 도구 (2026-10-15)

민재형: "상태평가가 제일 중요 — 다양한 값으로 넣어서 우리랑 같은지 시험해봐".
SafetyMan(공단 2007 건축물 종합평가 시스템)을 이 PC에서 자동으로 돌려 `server/sitok/rating.py` 결과와 비교한다.
**SafetyMan 화면을 마우스·키보드로 조작하므로 도는 동안 PC를 만지지 말 것.** 엑셀(숨은 창)·SafetyMan은 끝나면 모두 끈다.

- `sfm.py` — SafetyMan 저장 파일(.sfm, MFC CArchive) 읽기·쓰기. 다산은혜교회 파일로 구조를 맞췄고 원본과 바이트까지 같게 다시 써짐.
  부재 칸 순서(강도·탄산화·균열·표면노후 같음): 0 기둥, 1 내력벽, 2 슬래브, 5 큰보, 6 작은보(3·4 = 테두리보·접합부로 보임).
  강도 저장값 = MPa × 101.98, 탄산화는 cm. 층 머리 66바이트·탄산화 뒤 80바이트·층 끝 48바이트는 뜻을 모름(구조재료 RC/SRC/철골 등 — 아직 확인 안 함).
- `smrun.py` — SafetyMan 실행 → Ctrl+O로 열기 → 평가수행 → 숨은 엑셀 결과 읽기(채운 칸 수가 3초 그대로면 끝) → 저장 안 하고 끔.
  엑셀 "인증 마법사"는 보이는 즉시 닫음(COM 막힘). 파일을 실행 인자로 주면 SafetyMan이 바로 꺼짐.
- `t_diff.py <건수> <시작 seed>` — 무작위 입력(층 1~4, 부재 개수·결함 분포·강도·탄산화·기울기·침하) 비교.
- `t_rule.py <세트>` — 부재마다 정한 조건(균열 반올림·면적률)으로 부재 점수 비교. `t_area.py` — 면적률 20% 이상 개수 0~10 표.

결과·시험 파일은 `%TEMP%\safetyman_check`(SM_WORK로 바꿀 수 있음). 원본 다산 파일은 `바탕화면\시특법 견본\정밀\상태평가-다산은혜교회.sfm`(읽기만).

10/15 결과: 목표 시험 부재 210건 전부 일치, 무작위 75건 부재 점수·등급 전부 일치(7건은 마지막 자리 0.01 — x.xx5 경계에서 SafetyMan 내부 숫자 오차).
이때 고친 규칙(rating.py): 평균 → 등급 0.5 올림, 균열 면적률 20% 이상 = 평균 × (1 + 0.1 × 비율), Choquet 항목 하나면 그 점수.
