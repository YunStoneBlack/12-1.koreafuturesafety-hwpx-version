# SafetyMan ↔ 우리 상태평가 비교 도구 (2026-10-15)

민재형: "상태평가가 제일 중요 — 다양한 값으로 넣어서 우리랑 같은지 시험해봐".
SafetyMan(공단 2007 건축물 종합평가 시스템)을 이 PC에서 자동으로 돌려 `server/sitok/rating.py` 결과와 비교한다.
**SafetyMan 화면을 마우스·키보드로 조작하므로 도는 동안 PC를 만지지 말 것.** 엑셀(숨은 창)·SafetyMan은 끝나면 모두 끈다.

- `sfm.py` — SafetyMan 저장 파일(.sfm, MFC CArchive) 읽기·쓰기. 다산은혜교회 파일로 구조를 맞췄고 원본과 바이트까지 같게 다시 써짐.
  부재 칸 순서(강도·탄산화·균열·표면노후 같음): 0 기둥, 1 내력벽, 2 슬래브, 5 큰보, 6 작은보(3·4 = 테두리보·접합부로 보임).
  강도 저장값 = MPa × 101.98, 탄산화는 cm. 층 머리 다섯째 정수 = 구조재료(0 RC·1 SRC·2 철골조). 강재 칸(기둥·큰보·작은보 3칸)은
  화면에서 값 넣고 저장한 파일 비교로 찾음: 탄산화 뒤 = (28바이트) 강재규격 줄(측정·설계 단면적 cm²) · 내화피복 줄(측정·설계 두께 cm, 손상) (28바이트),
  층 끝 = 용접(A~E 개수) · 볼트(불량·조사) · 강재부식도(A~E 개수) (12바이트).
- `smrun.py` — SafetyMan 실행 → Ctrl+O로 열기 → 평가수행 → 숨은 엑셀 결과 읽기(채운 칸 수가 3초 그대로면 끝) → 저장 안 하고 끔.
  엑셀 "인증 마법사"는 보이는 즉시 닫음(COM 막힘). 파일을 실행 인자로 주면 SafetyMan이 바로 꺼짐.
- `t_diff.py <건수> <시작 seed>` — 무작위 입력(층 1~4, 부재 개수·결함 분포·강도·탄산화·기울기·침하) 비교.
- `t_rule.py <세트>` — 부재마다 정한 조건(균열 반올림·면적률)으로 부재 점수 비교. `t_area.py` — 면적률 20% 이상 개수 0~10 표.
- `t_steel.py` — 강재 섞인 건물(층마다 구조재료·콘크리트 부재·강재 항목)을 .sfm으로 만들어 SafetyMan 부재 점수 보기.
- `t_steel_diff.py <건수> <시작 seed> [--steel]` — 무작위 RC·철골조·SRC·형 방식(같은 층 RC + 철골조 표본층) 건물 비교(--steel = 강재 층만).

결과·시험 파일은 `%TEMP%\safetyman_check`(SM_WORK로 바꿀 수 있음). 원본 다산 파일은 `바탕화면\시특법 견본\정밀\상태평가-다산은혜교회.sfm`(읽기만).

10/15 결과: 목표 시험 부재 210건 전부 일치, 무작위 75건 부재 점수·등급 전부 일치(7건은 마지막 자리 0.01 — x.xx5 경계에서 SafetyMan 내부 숫자 오차).
이때 고친 규칙(rating.py): 평균 → 등급 0.5 올림, 균열 면적률 20% 이상 = 평균 × (1 + 0.1 × 비율), Choquet 항목 하나면 그 점수.

10/15 강재(철골조·SRC) — SafetyMan에서 확인해 rating.py에 넣은 규칙:
강재 항목 점수 = 강재규격(측정÷설계 단면적: 100↑ a · 95 b · 90 c · 75 d · 미만 e)·내화피복(강도와 같은 띠, 손상 b)은 부재 등급 점수 평균(반올림 없음),
용접·강재부식도는 개수 표 점수 평균, 볼트는 불량률(0 a · 5% 미만 b · 10% c · 30% d · 이상 e). 부재 점수 = Choquet(규격 0.5·용접 0.7·볼트 0.7·부식 0.9·내화피복 0.3).
철골조 층 = 기둥·큰보·작은보는 강재만(콘크리트 항목은 화면에 있어도 층 합산에 안 씀), 내력벽 없음, 슬래브는 콘크리트.
SRC 층 = 큰보·작은보는 콘크리트·강재 중 큰 점수, 기둥은 콘크리트만(화면 표시는 둘 중 큰 값이지만 층 합산은 콘크리트).
우리 SRC = 형 입력 방식(콘크리트 층 + 같은 층 철골조 표본층 따로)으로 계산. 강재 섞인 무작위 40건 중 38건, 강재 층만 40건 중 37건 일치
(나머지 = 0.01 경계 4건, 강재 항목 없는 철골조 층을 SafetyMan이 "0.00(A)"로 표시만 하는 1건). 자동조작 중 카카오톡 창이 뜨면 창 핸들 오류 — 다시 돌리면 됨.
남는 0.01 차이: SafetyMan 층·건물 합산 λ가 참값과 ±0.0001~0.0004 달라서(λ를 조합별로 거꾸로 구해 봄 — 반올림·이분법·뉴턴·걸음 방식 어느 것도 전부는 안 맞음).
층 합산 209개 중 204개가 소수 둘째 자리까지 같음. 등급이 바뀌려면 값이 등급 경계(2·4·6·8)에서 0.001 안이어야 함.
